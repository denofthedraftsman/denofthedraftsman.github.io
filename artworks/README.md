# How to use this system

1. Create an images folder in your repository to hold your scanned JPEG/PNG files.
2. When you finish a new drawing, upload the scan to the images folder.
3. Duplicate template.html and name it after the drawing (e.g., gearbox.html). Edit the file to point to your new image and add your description.
4. Open index.html and copy/paste a <a href="..." class="gallery-item">...</a> block to add the new piece to your homepage grid.
5. Commit and push the changes to GitHub. Your live site will update in seconds.
